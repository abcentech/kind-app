# WEEK ONE SUBSERIES
## THE OWNERSHIP CODE

> **Series:** The Stewardship Code — *Secrets to Managing Money*

---

### God Owns It; I Manage It

### Weekly Primary Passage

Luke 16:1–2

### Weekly Question

Whose money, time, talents and opportunities am I managing?

### Weekly Objective

By the end of the week, teenagers should understand that God owns everything, that they are
managers of entrusted resources and that every resource carries a divine assignment.
