# SHORT 23 — SOLVE A PROBLEM
> Companion to Episode 23 · *The Stewardship Code in 60 Seconds* · 30–60s

**Opening:** "Welcome to **The Stewardship Code in 60 Seconds**."

**🎯 Hook:** Joseph walked into Pharaoh’s throne room as a prisoner. He walked out
governing Egypt. What changed? He brought a solution.

**📖 Scripture:** “Forasmuch as God hath shewed thee all this, there is none so discreet
and wise as thou art.” — Genesis 41:39

**💡 Truth:** Everyone in Egypt could see the coming famine. Joseph brought a plan, a
system and a long-term strategy. Value is created when wisdom and skill meet a real
problem. Look around you — someone is struggling with a school subject, a phone, a mess,
a message they can’t write. A steward asks, “What can I do to help?” People normally
exchange money for something they genuinely value, so don’t only ask how to make money.

**🚀 Challenge:** List three problems around you. For each, name who it affects, what
skill could help, and one small solution you can test.

---
**Quote graphic:** “Don’t only ask how to make money. Ask what problem you can solve.”
