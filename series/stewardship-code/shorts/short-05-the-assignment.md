# SHORT 05 — THE ASSIGNMENT
> Companion to Episode 05 · *The Stewardship Code in 60 Seconds* · 30–60s

**Opening:** "Welcome to **The Stewardship Code in 60 Seconds**."

**🎯 Hook:** Two teens, identical phones. One scrolls for hours. One learns editing,
designs flyers and serves a church media team. Same device. Different assignment.

**📖 Scripture:** “Occupy till I come.” — Luke 19:13

**💡 Truth:** The master didn’t hand out money to be admired or displayed — he expected
it used. Every resource God gives carries an assignment: to meet needs, build capacity,
create value, bless people, advance His Kingdom. A phone can be a distraction or a
classroom, a camera or a business tool. Pleasure isn’t automatically sinful — but
purpose must lead pleasure.

**🚀 Challenge:** Pick one resource you own and write three productive assignments it
can fulfil.

---
**Quote graphic:** “The object is the same. The assignment decides everything.”
