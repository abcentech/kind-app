# WEEK THREE SUBSERIES
## THE MASTERY CODE

> **Series:** The Stewardship Code — *Secrets to Managing Money*

---

### Christ My Master, Money My Servant

### Weekly Primary Passage

Luke 16:9–13

### Weekly Question

Do I control money, or has money begun to control me?

### Weekly Objective

Teenagers will learn to reject greed, comparison, material identity, pressure and the love
of money while directing money towards godly purposes.
